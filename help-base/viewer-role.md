# Viewer Role

The Viewer role provides read-only access to journeys and basic analytics, ideal for stakeholders who need visibility without editing capabilities.

## Overview

Viewers can:

- View published journeys
- Preview journey content

Viewers cannot:

- Create or edit journeys
- Create or edit AI guides
- Manage end users or makers
- Access settings
- Publish or modify content

## When to Assign Viewer Role

Ideal for:

- **Executives**: Oversight without details
- **Stakeholders**: Progress visibility
- **Reviewers**: Pre-publish approval
- **Consultants**: Advisory role
