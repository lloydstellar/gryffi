# Manager Role

The Manager role provides content oversight and user management capabilities without full administrative access.

## Overview

Managers can:

- Create and manage all journeys
- Create and manage AI guides
- Manage end users and groups
- Send invitations
- View comprehensive analytics
- Publish and unpublish journeys

Managers cannot:

- Manage makers
- Configure organization settings
- Configure system settings
- Access API keys

## When to Assign Manager Role

Ideal for:

- **Team leads**: Overseeing content teams
- **Training managers**: Managing learning content
- **HR managers**: Employee onboarding journeys
- **Content supervisors**: Quality control
- **Department heads**
